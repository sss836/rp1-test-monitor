# 原生 App 界面改版

按用户确认的白蓝色概念效果图，将现有 PySide6 原生上位机改成 App 布局。此处的截图是修改后的 Qt 程序实际渲染，不是再次生成的设计图；数据来自内存模拟样本，未连接机器人、后端或数据库。

## 已落实的页面

- 整机健康：首页显示 RP1 品牌素材、机器人概览、电池电量/电压/电流/温度、最高电机温度、主机温度/负载、电机健康反馈覆盖。电池条仅在收到有效 SoC 时显示，缺失值不补零。
- 部件监测：电池供电、原始保护位、计算功率、主机热区、监测来源、电机温度/MOS/原始故障表格。
- 趋势分析：默认选择温度，增加电池电压、电流、电量与主机负载选择；保留原有实时曲线和关节反馈表。首页额外显示最近60秒温度趋势；断点保留，新采集实例不连接旧曲线。
- 告警记录：显示真实上报的故障/保护与监测缺口，以及本次打开窗口期间最多100条状态变化。该记录不持久化，不冒充数据库告警历史。没有将效果图的演示温度预警线写成实际规则。
- 设备设置：原有采集服务、SSH目标与密钥配置移入该页；“切换机器人”进入连接设置，通过采集服务地址切换。

首页保持“模拟数据·非实机”或 ROS 来源提示；失联后清空当前健康数值。仍沿用现有健康判断规则，不根据在线或缺失故障码给出健康通过结论。具体数据接入边界见 [HEALTH_IMPLEMENTATION.md](HEALTH_IMPLEMENTATION.md)。

## 修改位置与技术选择

- `src/rp1_monitor/app_shell.py`：新增 App 布局，复用已有 MonitorWindow 的只读连接、SSH、实时数据接收与健康渲染。使用 Qt 原生控件、Qt SVG 线条图标和 pyqtgraph，沿用现有依赖，避免重写通信或引入浏览器容器。
- `src/rp1_monitor/desktop.py`：桌面启动入口使用新布局；退出后显式清理窗口，确保 Qt 图形资源在 QApplication 结束前释放。
- `tests/test_app_shell.py`：覆盖五页导航、趋势控件可见、断连隐藏、原始故障记录、新 stream 温度曲线隔离、桌面命令正常退出。

后台采集、数据库结构、中央大屏以及已有安装包未在这次界面改版中替换。本次为源码更新；从当前工程的桌面启动命令即可使用新界面。渲染图中的手机屏为视觉参考，本次没有新增手机安装包。
