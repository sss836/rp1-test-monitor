## 页面结构

顶部导航切换页面，同一时间只显示一个工作内容区。每台机器人都有独立地址；机器人选择器在当前页面切换设备，设备总览卡片进入对应整机页。

地址可直接打开和刷新，支持浏览器前进/后退及平台挂载前缀。HTML shell 不包含设备数据，原 API 鉴权继续生效。未知机器人显示提示；连接失败而尚未核对身份时显示等待状态，不自动替换成其他设备。

整机健康卡可直接进入电池、关节状态、主机负载三个独立详情页，整机页增加本次开机时长。热成像及核心进程分别从关节、主机页继续进入。新增统计、配对 RMS、时长来源与验证见 [部件详情页](COMPONENT_PAGES.md)。

整机页模型区提供“三维结构 / 整机热像”两个子视图。热像使用与完整温度页相同的实际面板、数据和点击控制，不复制SVG或关节ID；顶部来源标记及当前28关节演示中的4个待定位入口仍保留。点击每个图点或待定位按钮进入精确关节详情，亦可通过“打开完整关节热像”查看完整列表。键盘方向键、Home/End可切换子视图。

三维结构首次显示时才加载；切到热像或离开整机页立即停止Three渲染，返回结构后重新计算尺寸并绘制。隐藏历史页停止曲线查询与绘制，数据告警仅在对应页刷新。设备封面流仅在总览显示。手机顶部导航可收起，表格在自身区域滚动。

## 温度显示

默认“热成像色谱”采用深色仪器视图、蓝紫至橙黄/浅黄色谱及软边热区。可切回“红色深浅”，两种模式使用相同的温度、时间和配置阈值。没有增加依赖、模型请求或新的采集接口。

- 图上逐关节显示独立测点，每个点使用该关节自身已配置电机/MOS读数的最高值；同一部位的多轴关节分别显示温度、色谱和 J 索引。右侧保留电机、MOS、限值、状态与映射说明。示温范围汇总有效关节读数，不是整机表面的最低/最高温度。
- 色标使用设备配置的显示上下限，不随每次数据自动缩放。颜色只用于显示；超温仍由配置阈值与后端证据判断。
- 缺失、过期或判据未配置的区域保持灰色；断线清除旧热区，切换显示模式不会恢复缓存温度。
- 测点附近的软边用于视觉定位，没有生成连续表面温度。同部位多轴偏移只用于示意排布，不是精确安装坐标。页面明确标示“关节测温示意 · 非热像相机”。
- 点击部位或关节名称仍打开温度曲线与持久告警详情，支持键盘 Enter/空格。24/28 自由度配置继续使用各设备的中央档案，真实部位映射待实机确认。
- 当前模拟24关节配置显示24个图点；28关节配置显示24个图点及4个待定位关节。未确认位置的关节保留独立温度和精确详情入口，确认映射后才定位到图上，不猜位置。刷新和切换机型后清除旧点，保留正在操作的测点焦点。
