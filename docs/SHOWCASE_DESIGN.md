## 展示与数据

页面依次呈现整机展台、设备封面流、关节温度与健康、历史曲线、可展开的进程／存储／关节明细，以及诊断入口。原有温度详情和 Agent 对话继续作为覆盖层；管理员仍使用独立工作台。未引入正式测试成绩、虚构用例时长或 MTBF 数值。

首屏的设备、自由度、温度，以及环绕卡片中的电量、温度和 CPU 均取自原有监控快照。设备轮播只展示实际登记记录，切换后整页与诊断上下文同步。模拟来源始终标为“模拟数据 · 非实机”。平台连接中断、设备停用或观测过期时，新增实时数值保持未知；断线后切换设备不会恢复缓存读数，只有新的成功响应才恢复。

展示采用指定的 `#e8edf8` 背景、`#ffffff` 表面、`#263451` 正文、`#596a83` 次要文字、`#bdcce4` 边框和 `#4165a0` 主色。标题优先本机中文衬线字体，正文使用中文无衬线与系统字体；无在线字体请求。内容宽度上限 1200px，卡片与控件使用 20px 圆角，模糊不可用或减少透明度时回退实色表面。详细数据表在自身区域滚动。

## 动效与控制

| 效果 | 实现与时序 | 操作与降级 |
|---|---|---|
| 真实三维结构 | Three.js 加载本地完整 GLB；首次向左展示8秒，不循环 | 鼠标／触摸旋转、缩放、键盘左右键和按钮、Home复位；进度、错误重试、WebGL不可用时静态图 |
| 环绕数据展台 | CSS 3D平面数据卡，原生Web Animations控制，12秒一轮向左循环 | 悬停或聚焦暂停，前后按钮切换；减少动画时三项平铺 |
| 流动背景 | CSS渐变10秒循环，小幅向左移动 | 全局暂停入口；减少动画使用固定背景 |
| 设备封面流 | 本地Swiper，800ms切换，非循环、无自动播放 | 拖动、按钮、区域内左右键，边界按钮禁用；减少动画时展平、取消过渡 |

基础交互反馈为320ms。持续运动可用顶部「暂停动效」停止；页面不可见时暂停背景和环绕运动，三维展台离屏时停止渲染，初次展示完成后按需绘制。模型像素比上限为1.5。手机保留纵向自然滚动，模型查看同时提供按钮替代手势。

RP1.3模型是静态结构资产，不随实时关节反馈运动，也不证明24／28自由度实机的物理映射。温度部位仍依据当前机器人已配置且匹配的映射。模型约5.12MiB，库、解码器和模型均本地打包，运行无需外网、npm或CDN。版本、来源哈希、许可证和构建步骤见 [素材及构建说明](SHOWCASE_ASSETS.md)。
