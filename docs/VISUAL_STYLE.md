# v0.1.1 浅蓝品牌视觉修订

本轮按用户提供的 ROBO PARTY / RP1 参考图改版现场 Qt App 和网页大屏：浅冰蓝背景、细网格、海军蓝正文、亮蓝强调、真实品牌Logo和白蓝RP1机器人素材。

## 具体改动

| 部位 | 实现 | 原因 |
|---|---|---|
| 品牌区域 | 真实Logo、RP1静态示意、浅蓝弧环、分段蓝线 | 延续参考图的品牌语言 |
| 页面背景 | CSS低透明度网格；Qt用QPainter画细线 | 两端一致，不引入外部依赖或大背景图 |
| 监控主体 | 白色面板、深色数字、等宽数据、明确单位 | 连续查看曲线和表格时保持可读 |
| 交互 | 亮蓝主按钮、选中设备侧边标记、可见焦点 | 清楚区分操作与当前选中状态 |
| 数据来源 | 继续显著标记“模拟数据 · 非实机” | 机器人品牌示意不能当作实时姿态或实机验证 |
| 异常 | 深红、琥珀色及文字提示 | 浅色主题下仍能识别上传异常、过期和缺失 |
| 小窗口 | 网页响应式、Qt左栏滚动、表头按宽度分配；SVG按实际尺寸重绘、轴文字12px | 避免输入框/单位被截断和坐标轴缩得难以辨认 |

没有加入3D姿态、控制按钮或新采集功能。机器人图是静态品牌示意；既有只读订阅、独立上报、历史补传、鉴权和正式测试隔离保持原有设计。

## 颜色与字体

- 背景 `#eef5ff`；面板 `#ffffff`；正文 `#142441`。
- 次要文字 `#576c88`；主强调 `#2b59e8`。
- 网页正常状态 `#14735b`；警告 `#925709`；异常 `#b73443`。
- 中文沿用本机 Noto Sans CJK SC / Microsoft YaHei / 系统字体，数值使用等宽或tabular figures；无需在线字体服务。

按基础色对计算：正文/白底对比度15.46，次要文字/浅蓝底4.90，主蓝/白底5.68，绿色/白底5.78，警告/浅黄底5.41，红色/白底5.86。此项是已选色对计算，不冒充对所有控件状态的完整无障碍认证。
